WellFlow · 资产库 & 场景 AI 接口文档

数据保存在本地 JSON（assets_data/library.json），图片落盘 static/assets/ 与 static/scene_ai/
Base URL：http://127.0.0.1:8000 · 更新于 2026-09-15

一、资产库 CRUD（/api/assets）

GET/api/assets
查询资产列表，支持分类 / 来源 / 关键词（描述式搜索） / 维度（多选）组合过滤。返回列表 + 分类统计。
参数类型必填说明
categorystring否分类：brand 品牌资产库 / reference 参考素材 / model 模特库 / outfit 穿搭库 / scene 场景库；不传返回全部
scopestring否来源：official 官方 / mine 我的
qstring否关键词，空格/逗号/顿号分词，任一命中即返回（OR）；支持"去尾字"变体（如"夏天"→"夏"），可输入 ID、名称、标签、一句话描述或自然语言描述
dimsstring否JSON 字符串，维度多选过滤（多维之间 AND、维度内任一命中即匹配）。如 {"空间类型":["卧室","厨房"],"天气":["晴天"]}
返回示例：
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": "WF-S011",
        "category": "scene",
        "name": "夏日海边沙滩",
        "description": "阳光、沙滩与海浪，适合夏日度假风格拍摄。",
        "tags": "海边 沙滩",
        "scope": "mine",
        "dims": { "空间类型": ["沙滩"], "天气": ["日落"] },
        "image": "/static/assets/xxxx.png",
        "created_at": "2026-09-15 10:30:00"
      }
    ],
    "total": 8,
    "stats": { "brand": 5, "reference": 27, "model": 12, "outfit": 8, "scene": 8 }
  }
}
POST/api/assets
创建资产（multipart/form-data），自动生成 ID（如 WF-S012）。
参数类型必填说明
categorystring是分类 key（同查询接口）
namestring是资产名称
descriptionstring否一句话描述新增
tagsstring否标签，空格或顿号分隔
scopestring否默认 mine
dimsstring否JSON 字符串，维度值统一存为数组。如 {"空间类型":["摄影棚"],"天气":["晴天"]}
imagefile否图片文件（jpg/jpeg/png/gif/webp/bmp），保存到 /static/assets/
image_urlstring否图片 URL（http/https 或 /static 开头），与 image 二选一
返回：{"code":0,"data":{资产对象}}
PUT/api/assets/{asset_id}
更新资产（multipart/form-data）。支持修改分类；上传新图片时自动删除旧图；不传 image/image_url 时保留原图。前端「编辑资产」页即调用此接口。
参数类型必填说明
asset_idstring是路径参数，资产 ID（如 WF-S011）
categorystring否分类 key，传入则更新分类（校验在 5 类内）新增
namestring是资产名称
descriptionstring否一句话描述新增
tagsstring否标签
scopestring否来源（不传默认 mine，建议编辑时带上原值）
dimsstring否JSON 维度（多值数组）
imagefile否不传则保留原图
image_urlstring否不传则保留原图
错误：资产不存在 → HTTP 404 {"detail":"资产不存在: xxx"}；分类非法 → HTTP 400 {"detail":"未知分类: xxx"}
DELETE/api/assets/{asset_id}
删除资产，并清理本地图片文件。
参数类型必填说明
asset_idstring是资产 ID
返回：{"code":0,"data":{"deleted":"WF-S011"}}

二、场景 AI 提取（/api/scene）

POST/api/scene/ai-extract
上传原图，提交 AI 后台生成场景图。接口秒级返回任务 ID，AI 在线程中处理（约 30~60 秒），处理结果写入 static/scene_ai/，前端轮询状态接口获取结果。
参数类型必填说明
imagefile是原图（≤15MB）
promptstring否生成指令，默认："提取这张图片中的场景部分，生成场景图片"
返回示例：
{
  "code": 0,
  "data": {
    "task_id": "1789453922896_226e97",
    "orig_url": "/static/scene_ai/orig_1789453922896_226e97.png",
    "status": "processing"
  }
}
模型自动降级链：mai-image-2.5 → gpt-image-2.5-flare → gpt-image-2，任一成功即返回；408/429/5xx 自动重试 1 次，超时 240 秒。gpt 系对含人物图可能被安全系统拒绝，此时自动切换后续模型。生成过程中同步用 gemini-3.7-flash 识别图片 5 维场景标签（空间类型/地域环境/季节/天气/背景风格），随 dims 返回。
GET/api/scene/ai-status?task_id=xxx
查询 AI 任务状态。前端建议每 3 秒轮询，直到 done 或 failed。任务完成后返回场景图地址、识别到的 5 维标签与 Tokens 消耗。
参数类型必填说明
task_idstring是提交接口返回的任务 ID
返回示例（done）：
{
  "code": 0,
  "data": {
    "task_id": "1789453922896_226e97",
    "status": "done",
    "orig_url": "/static/scene_ai/orig_xxx.png",
    "scene_url": "/static/scene_ai/scene_xxx.png",
    "model": "mai-image-2.5",
    "dims": { "空间类型": ["摄影棚"], "背景风格": ["极简"] },
    "usage": { "input_tokens": 873, "output_tokens": 1017, "total_tokens": 1890 },
    "error": ""
  }
}
返回示例（failed）：
{
  "code": 0,
  "data": {
    "status": "failed",
    "error": "gpt-image-2: HTTP 400 {...}; mai-image-2.5: HTTP 408 timeout"
    // 其他字段同上；error 汇总各模型失败原因
  }
}

三、公共字段说明

字段类型说明
idstring资产 ID，自动生成：品牌 WF-B001 / 参考 WF-R001 / 模特 WF-M001 / 穿搭 WF-O001 / 场景 WF-S001 起
categorystringbrand / reference / model / outfit / scene
namestring资产名称
descriptionstring一句话描述新增，编辑页「一句话描述」字段
tagsstring标签文本
scopestringofficial（官方）/ mine（我的）
dimsobject维度字典，值为数组（多选）。如 {"空间类型":["卧室","厨房"],"季节":["夏"]}。场景库维度：空间类型 / 地域环境 / 季节 / 天气 / 背景风格
imagestring图片地址（/static/assets/ 或外链）；无图资产该字段为空字符串
created_atstring创建时间 yyyy-MM-dd HH:mm:ss
statusstringAI 任务状态：processing / done / failed
scene_urlstringAI 生成的场景图地址（仅 AI 接口）
usageobjectAI Tokens 消耗明细（input/output/total）

四、前端页面

页面说明
static/资产库-场景库.html资产库主页：5 分类 Tab、维度多选筛选（选完点搜索才查询）、卡片列表、创建场景、编辑/删除
static/编辑资产.html新增编辑表单：素材名称 / 分类（可改）/ 一句话描述 / 标签 / 素材图片（上传或更换），保存调 PUT /api/assets/{id}，通过 postMessage 通知父页刷新
static/创建场景.html选图 → 压缩 → 提交 AI 任务 → 跳转确认入库页
static/创建场景-确认入库.htmlAI 处理进度轮询、5 维标签多选面板（AI 自动补选识别到的标签）、确认入库（POST /api/assets）
通用返回格式：{"code":0,"data":…}；code=0 成功，code≠0 失败（msg 含原因）。数据文件：assets_data/library.json；图片目录：static/assets/（资产图）、static/scene_ai/（AI 场景图，已 gitignore）。
